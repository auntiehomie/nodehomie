# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to the repository owner privately via
GitHub's private vulnerability reporting (Security tab -> Report a vulnerability),
or open a GitHub Security Advisory. Do not open public issues for security bugs.

We aim to acknowledge reports within 48 hours. This project is used by paying
customers; please include reproduction steps and impact assessment where possible.

## Scope

- Vulnerabilities in this repository's code or its dependencies
- Exposed secrets or credentials
- Authentication/authorization bypasses

## Security Settings

- Dependabot alerts and security updates: enabled
- Secret scanning and push protection: enabled (where plan allows)
- Default branch protection requires review
